# Graduate Projects

Projects from my M.S. in Data Science at Northwestern University. Each folder links to the project's own repository.

| Project | What it does |
|---|---|
| [csv-to-jsonlines](https://github.com/dillonsingh26/csv-to-jsonlines) | Go command-line tool that converts CSV files to JSON lines |
| [anscombe-go-stats](https://github.com/dillonsingh26/anscombe-go-stats) | Testing a Go statistics package against Python and R using the Anscombe Quartet |
